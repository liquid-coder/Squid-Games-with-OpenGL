Squid Games Simulation - 3D OpenGL Game
A 3D implementation of popular Squid Games challenges using PyOpenGL. Navigate through three intense survival games where one wrong move means elimination!

🎮 Games Included
1. Red Light, Green Light
Navigate to the finish line without getting caught moving during "Red Light"

Randomly switching traffic lights control movement

Third-person/first-person camera toggle

Elimination if detected moving during red light

2. Dalgona Challenge
Trace intricate shapes (Circle, Square, or Triangle) without breaking the outline

Green line appears where you successfully walk

Must trace at least 99.5% of the shape to complete

Real-time progress tracking with visual feedback

3. Glass Bridge
Choose correct glass steps across a dangerous bridge

7 pairs of steps - one safe, one dangerous in each pair

Randomly generated safe paths each game

Teleportation movement with strategic choices

"M" key reveals hints for next safe step

✨ Features
Full 3D Environment with OpenGL rendering

Roblox-style character with player ID "001"

Toggleable camera (third-person & first-person views)

Progressive difficulty across three distinct games

Randomized challenges for replayability

Visual feedback systems (colored steps, progress bars, hints)

Complete game flow with menu, gameplay, win/lose states

🎯 Objective
Survive all three challenges to win 456 billion Zimbabwean dollars! Each game tests different skills: timing, precision, and strategic decision-making.

🕹️ Controls
WASD: Character movement (Levels 1 & 2)

A/D: Choose left/right steps (Level 3)

W/R: Move forward/sideways (Level 3)

M: Toggle hints (Level 3)

Right-click: Toggle camera view

ESC/R: Return to menu

P: Start game from menu

🛠️ Tech Stack
Python with PyOpenGL for 3D graphics

GLUT for window management and input

Mathematical calculations for game logic and collision detection

Randomization algorithms for unpredictable challenges

📁 Project Structure
Complete single-file implementation

Modular functions for drawing, game logic, and input handling

State-based game management

Reusable graphics components
